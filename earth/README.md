# 🌏 나의 가상 지구본

손가락으로 돌려 보고, 확대하고, 나라와 도시를 찾아보고, 가 본 곳에 핀을 꽂아 두는 **3D 가상 지구본** 웹 앱입니다.
낮과 밤이 실제 시각의 태양 위치에 맞게 나뉘고, 나만의 여행 지도를 만들 수 있어요.
서버 없이 정적 파일만으로 동작하며, 휴대폰 홈 화면에 앱처럼 추가할 수 있습니다.

## 주요 기능

- **지구본 조작**: 한 손가락으로 돌리기(관성), 두 손가락으로 확대·축소·비틀기, 두 번 눌러 확대, 눌러서 나라 정보 보기, 길게 눌러 핀 꽂기
- **지도 스타일 4가지**: 가상 위성 · 정치 지도 · 심플 · 야간(도시 불빛)
- **레이어**: 국경선, 위도·경도 격자(10°/30°), 적도·회귀선·극권, 도시 마커와 이름, 대륙·대양 이름, 구름
- **낮과 밤**: 기기 시각으로 계산한 실제 태양 위치, 앞뒤 1년 시간 이동과 빠른 재생
- **검색**: 나라·도시를 한글, 영문, 한글 초성(예: `ㅍㄹㅅ` → 프랑스)으로 찾기
- **세계 시계**: 여러 도시의 현지 시각(서머타임 자동 반영, 한국과의 시차)
- **거리·항로**: 두 도시 또는 지도 위 두 지점 사이의 최단 경로(대권), 거리(km/마일), 대략적인 비행 시간
- **내 핀과 여행 기록**: 이름·메모·색상·이모지·분류가 있는 핀, 방문한 나라 색칠과 대륙별 통계
- **국가 퀴즈**: 나라 이름 맞히기 / 지구본에서 찾기 / 수도 맞히기, 최고 기록과 틀린 나라 복습
- **화면 저장**: 지금 보이는 지구본을 PNG로 저장·공유
- **가이드 투어**: 대륙을 차례로 돌며 소개
- **라이트/다크 모드**: 시스템 설정 따르기(기본) / 라이트 / 다크

## 파일 구성

```
지구본/
├─ index.html            앱 본체 (HTML, CSS, JS)
├─ world-data.js         세계 지도·국가·도시 데이터
├─ manifest.webmanifest  홈 화면 앱 설정
├─ sw.js                 서비스 워커 (오프라인 실행)
├─ icons/                앱 아이콘 5개
├─ .nojekyll             GitHub Pages 설정용 빈 파일
└─ README.md             이 설명서
```

모든 경로는 상대 경로(`./`)라서 `https://사용자명.github.io/저장소명/` 같은 하위 경로에서도 그대로 동작합니다.
`index.html`을 더블클릭해서 열어도(file://) 앱은 동작합니다. 다만 이때는 오프라인 캐시와 홈 화면 추가가 되지 않아요.

## GitHub Pages에 올리기

1. GitHub에 로그인한 뒤 오른쪽 위 **+ → New repository**로 새 저장소를 만듭니다. (예: `globe`, Public)
2. 저장소 화면에서 **Add file → Upload files**를 누르고, `지구본` 폴더 **안의 파일과 폴더 전부**를 끌어다 놓습니다.
   - `icons` 폴더도 함께 올려야 해요.
   - `.nojekyll`처럼 점으로 시작하는 파일이 안 보이면, 컴퓨터에서 숨김 파일 보기를 켜고 올려 주세요.
3. 아래쪽 **Commit changes**를 누릅니다.
4. 저장소의 **Settings → Pages**로 갑니다.
5. **Build and deployment**의 Source를 **Deploy from a branch**로 두고, Branch를 **main / (root)** 로 고른 뒤 **Save**를 누릅니다.
6. 1~2분 뒤 같은 화면 위쪽에 나오는 주소(`https://사용자명.github.io/저장소명/`)로 접속합니다.

## 휴대폰 홈 화면에 추가하기

**안드로이드 (크롬)**
1. 크롬에서 위 주소를 엽니다.
2. 오른쪽 위 **⋮ 메뉴 → 홈 화면에 추가**(또는 **앱 설치**)를 누릅니다.
3. 홈 화면에 생긴 "지구본" 아이콘으로 실행하면 주소창 없이 앱처럼 열립니다.

**아이폰 (사파리)**
1. 사파리에서 위 주소를 엽니다.
2. 아래쪽 **공유 버튼(□↑) → 홈 화면에 추가**를 누릅니다.
3. 이름을 확인하고 **추가**를 누릅니다.

## 저장·불러오기 사용법

기록(핀, 방문한 나라, 세계 시계 도시, 퀴즈 기록, 보기 설정)은 **이 기기의 브라우저에만** 저장됩니다.
기기를 바꾸거나 브라우저 데이터를 지우면 사라지니 가끔 파일로 저장해 두세요.

- **전체 저장**: 메뉴 → 💾 저장·불러오기 → **전체 저장**
  - `지구본_백업_2026-11-25.json` 같은 파일이 만들어져요.
  - 휴대폰에서는 공유 창이 열리면 "파일에 저장"이나 드라이브를 고르면 되고, 공유를 지원하지 않는 브라우저에서는 일반 다운로드로 저장돼요.
- **전체 불러오기**: 같은 화면에서 **전체 불러오기** → 파일 선택
  - 적용하기 전에 "핀 24개, 방문한 나라 12개, 저장일 …"처럼 미리 보여 줘요.
  - **합치기(기본)**: 같은 핀은 최근에 수정한 쪽을 남기고, 방문한 나라는 합치고, 퀴즈 최고 기록은 높은 쪽을 남겨요.
  - **덮어쓰기**: 지금 데이터를 파일 내용으로 바꿔요. 두 번 확인한 뒤 적용돼요.
  - 형식이 잘못되었거나 손상된 파일이면 이유를 알려 주고 기존 데이터는 그대로 둬요. 적용 도중 문제가 생기면 원래 데이터로 되돌려요.
- **핀 주고받기**: 내 핀 → ☑️ 선택 → 핀을 고르고 **저장**하면 핀만 담긴 파일이 만들어져요. 받은 핀 파일은 **핀 파일 불러오기**로 합칠 수 있어요.
- **자동 보관본**: 덮어쓰기 불러오기, 전체 삭제, 핀 여러 개 삭제 직전의 데이터를 최근 2개까지 자동으로 보관해요. 설정 → 자동 보관본에서 복원할 수 있어요.
- 30일 넘게 저장하지 않았고 핀이 5개 이상이면 메뉴에 저장 안내가 나와요. 닫으면 7일 동안 숨겨져요.

## 유의사항

- **"가상 위성" 스타일은 실제 위성 사진이나 지형이 아니라** 위도와 노이즈로 숲·사막·설원 느낌을 꾸며 낸 색이에요. 구름과 도시 불빛도 꾸민 효과예요.
- 지도가 1:110m 해상도라 **작은 섬과 작은 나라**(모나코, 몰디브, 싱가포르, 태평양 섬나라 등)는 모양이 빠져 있어요. 수도 이름으로 검색하거나 도시 마커로 찾고, 핀으로 직접 추가할 수 있어요.
- 기록은 **해당 기기에만 저장**돼요. 정기적으로 "전체 저장"을 해 두세요.
- **파일을 고친 뒤 반영이 안 되면** `sw.js` 맨 위의 `CACHE_VERSION` 값을 올려 주세요(예: `'v1'` → `'v2'`). 다시 업로드한 뒤 앱을 한두 번 새로 열면 반영돼요.
- **홈 화면 아이콘을 바꿨다면** 홈 화면에서 앱을 지우고 다시 추가해야 새 아이콘이 보여요.
- WebGL을 쓸 수 없는 기기에서는 간단한 2D 화면으로 보여요. 이때는 구름과 부드러운 대기 빛무리 같은 효과가 빠져요.
- 글꼴은 처음 한 번 인터넷에서 받아 오고 그 뒤로는 저장된 것을 써요. 받지 못하면 기기 기본 글꼴로 보여요.
